# SpectraShield 1.0 — Security Operations Center (SOC) Frontend

The **SpectraShield Frontend** is a modern, high-performance Security Operations Center (SOC) web application built with **React 18**, **Vite**, **Tailwind CSS**, and **Radix UI Primitives**. It provides security analysts and end users with real-time threat telemetry, explainable risk scoring, interactive link sandboxing, and in-depth phishing analysis.

---

## Key Features & Visualizers

### 1. SOC Operations Dashboard (`Dashboard.tsx`)
- **Real-Time KPI Telemetry:** Displays total lifetime scans, high-risk detection counts, and average response times.
- **Top Impersonated Brands Analytics:** Dynamic visual breakdown of organizations targeted by attackers (e.g., Microsoft, Google, PayPal), backed by the `/dashboard/top-brands` API.
- **7x24 Incident Heatmap:** Time-of-day versus day-of-week incident density matrix backed by `/dashboard/risk-heatmap`.
- **Searchable Scan Ledger:** Complete historical incident table with risk level filtering (`All`, `High`, `Medium`, `Low`), sender address searching, and individual record deletion.

### 2. Explainable Threat Scoring
- **Dynamic Risk Gauge (`RiskMeter.tsx`):** Animated SVG circular gauge representing composite threat scores from 0.0 to 100.0 with adaptive color states:
  - `0 – 34`: **Low Risk / Legitimate** (Emerald Green)
  - `35 – 74`: **Suspicious / Warning** (Amber / Orange)
  - `75 – 100`: **High Risk / Malicious** (Crimson Red)
- **Granular Threat Breakdown (`RiskBreakdown.tsx`):** Horizontal risk factor progress bars decomposing the composite score into:
  - *Linguistic Manipulation* (Urgency, Fear, Authority, Scarcity)
  - *Brand Impersonation & Typosquatting*
  - *Header Authentication Anomaly*
  - *URL & Domain Reputation*
- **Explainable Reasoning Accordion (`WhyFlagged.tsx`):** Contextual explanations detailing why a specific email or URL was flagged, highlighting exact linguistic pressure phrases.

### 3. Cyber Killchain Attack Sequence
- Visualizes the 4-stage MITRE-aligned progression generated by the backend:
  1. *Deceptive Lure*
  2. *Credential Harvesting Portal*
  3. *Session Token Compromise*
  4. *Enterprise Asset Exfiltration*

### 4. Interactive Link Sandboxing (`LinkPreview.tsx`)
- Safely previews suspicious URLs inside an isolated iframe sandbox without triggering payload execution.
- Displays SSL/TLS certificate assurance badges (Valid, Expired, Self-Signed, Untrusted).
- Shows WHOIS domain age indicators and multi-engine VirusTotal consensus metrics.

### 5. Extension Demonstration Sandbox (`GmailDemo.tsx`)
- Built-in interactive simulator demonstrating how SpectraShield's browser extension evaluates email inbox rows and injects risk badges in live webmail environments.

### 6. Theme Engine (`ThemeProvider.tsx`, `ThemeToggle.tsx`)
- Built-in dark and light SOC aesthetic themes with smooth transitions and persistent browser storage.

## Setup & Running Locally

### Prerequisites
- Node.js 18+ LTS
- npm or pnpm

### 1. Install Dependencies
```powershell
npm install
```

### 2. Environment Configuration (Optional)
The frontend connects to the backend API at `http://localhost:8000` by default. To point to an alternative backend host, create `.env.local`:
```env
VITE_API_URL=http://localhost:8000
```

### 3. Run Development Server
```powershell
npm run dev
```
The application will launch at `http://localhost:5173`.

### 4. Build for Production
```powershell
npm run build
```
Compiled production bundles are output to `dist/`.
